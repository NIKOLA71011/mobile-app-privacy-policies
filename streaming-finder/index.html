プライバシーポリシー

対象アプリ: 配信サーチ  |  制定日: 2026年9月10日

本アプリ「配信サーチ」(以下「本アプリ」)は、個人開発者(以下「開発者」)が提供するiOSアプリです。本ポリシーは、本アプリの利用にあたって取り扱う情報について説明するものです。

1. 端末内にのみ保存される情報

以下の情報は、開発者のサーバーには送信されず、お使いの端末内にのみ保存されます。アプリを削除すると、これらのデータも端末から削除されます。本アプリにはアカウント登録・ログイン機能はありません。

  • 契約中として選択した配信サービスの一覧
  • 「見た」「お気に入り」として登録した作品の一覧
  • 「ランダムで選ぶ」機能の設定(契約中サービスに限定するか、映画/ドラマのどちらを対象にするか)

本アプリには開発者が運用する独自のサーバーは無く、後述する外部サービスに端末から直接通信する構成になっています。

2. 外部サービスに送信される情報

機能送信される情報送信先
作品検索・トレンド表示・配信状況の取得・ランダム選出 検索キーワード、選択した作品ID、契約中サービスとして選んだ配信サービスのID(氏名・端末識別子等の個人情報は含まれません) The Movie Database (TMDB)

本アプリは The Movie Database (TMDB) のAPIを利用していますが、TMDBによる承認・認定を受けたものではありません(This product uses the TMDB API but is not endorsed or certified by TMDB)。TMDB側での情報の取り扱いについては、TMDBが公開するプライバシーポリシーをご確認ください。

3. 広告について

本アプリは、Google AdMobによるバナー広告を表示しています。広告配信にあたり、Google Mobile Ads SDKが端末の広告識別子(IDFA)や広告表示に関する情報を取得する場合があります。これらの情報の取り扱いについては、Googleの以下のポリシーをご確認ください。

  • Google 広告 ポリシーと規約
  • AdMob 広告のパーソナライズについて

iOSでは、初回起動時等にApp Tracking Transparency(ATT)によるトラッキング許可の確認が表示される場合があります。許可しない場合でも、パーソナライズされていない広告が表示され、本アプリの基本機能は問題なくご利用いただけます。

4. 第三者への提供

開発者は、法令に基づく場合を除き、本アプリを通じて取得した情報を、上記に記載した目的以外で第三者に提供することはありません。

5. お子様のプライバシーについて

本アプリは13歳未満のお子様を主な対象としたサービスではなく、お子様の個人情報を意図的に収集することはありません。

6. 本ポリシーの変更

本ポリシーの内容は、法令の変更やアプリの機能追加に伴い、予告なく変更されることがあります。重要な変更がある場合は、本ページの更新をもってお知らせします。
