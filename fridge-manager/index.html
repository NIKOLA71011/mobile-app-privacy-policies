プライバシーポリシー

対象アプリ: ムダなし冷蔵庫  |  制定日: 2026年8月30日(2026年9月10日改定)

本アプリ「ムダなし冷蔵庫」(以下「本アプリ」)は、個人開発者(以下「開発者」)が提供するiOS/Androidアプリです。本ポリシーは、本アプリの利用にあたって取り扱う情報について説明するものです。

1. 端末内にのみ保存される情報

以下の情報は、開発者や第三者のサーバーには送信されず、お使いの端末内にのみ保存されます。アプリを削除すると、これらのデータも端末から削除されます。

  • 登録した食材の名称・数量・賞味期限・登録日などの在庫データ
  • アプリの設定(通知のON/OFF、通知タイミングなど)
  • バーコード検索結果のキャッシュ(商品名・メーカー名)

2. 外部サービスに送信される情報

本アプリの一部機能は、以下の外部サービスと通信するために必要最小限の情報を送信します。

機能送信される情報送信先
バーコードによる商品名検索 スキャンしたバーコード番号(JANコード)のみ 開発者が運用するサーバー(Firebase Cloud Functions)を経由して、Yahoo!ショッピングの商品検索APIに送信されます。氏名・端末識別子などの個人情報は含まれません。
広告の表示 広告識別子(IDFA/AAID)、おおよその位置情報、端末情報など、広告配信・効果測定に必要な情報 Google社の広告サービス(Google AdMob)により収集される場合があります。詳細は下記「広告について」をご確認ください。

3. カメラの利用について

バーコードをスキャンする機能のためにカメラへのアクセス許可を求めます。カメラの映像は端末内でバーコードの読み取りにのみ使用され、画像として保存されたり外部に送信されたりすることはありません。

4. 通知について

賞味期限が近づいた食材をお知らせするための通知(ローカル通知)を端末内で生成します。この通知に関する情報が外部サーバーに送信されることはありません。

5. 広告について

本アプリでは、Google AdMobを利用して広告を表示しています。Google AdMobは、広告の表示・パーソナライズ・効果測定のために、広告識別子等の情報を収集する場合があります。詳細は、Google社のプライバシーポリシーをご確認ください。

  • Googleプライバシーポリシー
  • Googleパートナーによるデータ利用について

お使いの端末の設定から、広告のパーソナライズを制限することができます(iOS:「設定」→「プライバシーとセキュリティ」→「トラッキング」/「Appleの広告」、Android:「設定」→「Google」→「広告」)。

6. 第三者への提供

開発者は、法令に基づく場合を除き、本アプリを通じて取得した情報を、上記に記載した目的以外で第三者に提供することはありません。

7. お子様のプライバシーについて

本アプリは13歳未満のお子様を主な対象としたサービスではなく、お子様の個人情報を意図的に収集することはありません。

8. 本ポリシーの変更

本ポリシーの内容は、法令の変更やアプリの機能追加に伴い、予告なく変更されることがあります。重要な変更がある場合は、本ページの更新をもってお知らせします。
